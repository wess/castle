Features

Proxmox-style control, sized for one box.

Everything to run a homelab on a single Linux host — workloads, network, storage, and AI access in one daemon.

📦

Workloads

Full Docker container CRUD plus LXC system containers, with a web exec console over xterm.js and WebSockets.

💿

Images

List, pull, and remove images. Pulls run as background jobs with live progress so you never block the UI.

🌐

Network

Manage Docker networks, host bridges, and port-forwards — the plumbing your services need, in one place.

🗄️

Storage

ZFS, LVM, and directory pools alongside Docker volumes, so capacity is managed the way your host expects.

🧩

Apps catalog

1-click installs for Ollama, Tangle, Stohr, Jellyfin, Vaultwarden and more — multi-service installs included.

📡

Routing

*.local mDNS aliases plus auto-generated nginx vhosts, so every app gets a clean hostname.

🦙

Ollama console

Chat with persistent history and pull models as durable background jobs — local LLMs without the busywork.

🤖

Built-in MCP

A built-in MCP server exposes 16 tools to AI agents like Claude and Cline, so they can drive your homelab.

🎛️

GPU passthrough

NVIDIA passthrough via Docker DeviceRequests, managed by Castle, for AI workloads and transcoding.

Architecture

One daemon, three faces.

  • ✦castled — a Bun daemon exposing a REST + WebSocket API, routes, the MCP server, and background jobs.
  • ✦web — a React/Mantine SPA for the dashboard, consoles, and 1-click installs.
  • ✦castle CLI — the same control plane from your terminal.
  • ✦Host adapters — Docker over its unix socket, the lxc-* binaries, nginx vhost generation, and avahi mDNS.
  • ✦Auth — JWT with a single admin, or an optional auth-disabled mode for trusted dev.
castled (Bun daemon) │ REST · WS · MCP (16 tools) │ ┌─────────┼──────────┐ Docker LXC nginx (socket) (lxc-*) (vhosts) │ avahi · Ollama (mDNS) (HTTP)
Get started

Running in a few minutes.

Requires Bun. The first sign-up becomes the admin; castled binds on :4280 and the web dev server on :5173.

terminal 
# 1. install + configure
bun install
cp env.example .env

# 2. run (castled :4280, web :5173)
bun run dev

# 3. ship it to your box (SSH_HOST/USER/PASS in .env)
bun run deploy

Run your homelab from one place.

Open source under Apache 2.0. Self-host Castle on your box and keep your containers, data, and keys yours.
